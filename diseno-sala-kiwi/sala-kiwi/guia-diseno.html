Dirección de diseño

Escarcha y oro

Una sala de trofeos de noche: azul profundo como fondo, oro apagado solo donde algo merece atención (MVP, pentakills, la pestaña activa) y cifras tabulares para que los números se comparen de un vistazo. Sobrio, con profundidad sutil, sin brillos de casino.

Principio 1 · De un vistazo

Quién ganó, el marcador y el KDA son lo primero que se lee. Todo lo demás (curación, visión, tropas) vive en una segunda capa: pestañas o tablas.

Principio 2 · Color con texto

Azul y rojo identifican equipos; verde y rojo, resultados. Nunca solo el color: siempre acompañados de «Victoria», «Derrota», «Equipo azul» o un icono.

Principio 3 · El oro es escaso

Si todo brilla, nada destaca. El dorado se reserva para MVP, pentakills, el primer puesto del ranking, el foco de teclado y la navegación activa.

Piezas para plantillas

  • .site-header / .site-footer — layout común.
  • .stat-tile — resumen numérico.
  • .match-card → .team-block + .scoreboard + .roster__player.
  • .team-panel → .player-row (con .is-mvp).
  • .icon, .slot, .augment, .spell — casillas con fallback.
  • .badge — MVP, multikills, resultado.
  • .data-table con th[aria-sort] y td[data-value] — ordenable.
  • .tabs / .tab-panel — pestañas accesibles.

Accesibilidad e interacción

  • Foco visible: contorno dorado de 2 px en todo elemento interactivo; enlace «Saltar al contenido».
  • Tarjeta de partida entera clicable mediante un único enlace (sin anidar controles).
  • Iconos sin imagen llevan role="img" y aria-label.
  • Transiciones de 140–220 ms; se desactivan con prefers-reduced-motion.
  • Objetivos táctiles ≥ 44 px en navegación, pestañas y botones.
